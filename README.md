# Clicker Game (lb7-9)

Це повноцінна гра-клікер (SPA) створена на базі React + Vite. 

## Реалізовані функції:

1. **Клік-механіка**: Заробіток кредитів за допомогою натискань, відображення плаваючих чисел, обробка множників.
2. **Система апгрейдів**:
    - **Потужність кліку**: Збільшує дохід за клік (лінійно).
    - **Автоклікер**: Пасивний дохід щосекунди.
    - **Синергія**: Відсотковий множник до всіх доходів.
    - **Комбо-множник**: +5 до сили кліку за кожен рівень.
    - **Ефективність**: Значний бонус до пасивного доходу (+15/сек).
3. **Бонуси та антибонуси (Колесо Фортуни)**:
    - Позитивні ефекти (Золота жила x2, Божевілля x5).
    - Негативні ефекти (DDoS Атака -50%, Вірус-шифрувальник -90%, Баг у базі -20%).
    - Таймери та автоматичне завершення ефектів.
4. **Престиж**:
    - Можливість скинути прогрес після досягнення 100,000 Cr для отримання валюти *Duiktcoins*.
    - Duiktcoins надають глобальний множник (x1.5 за кожну монету) для наступних проходжень.
5. **Система скінів**:
    - Зміна глобальної теми та кольорів гри (через зміну CSS-змінних).
    - Скіни можна купувати як за звичайні кредити, так і за преміальну валюту (Duiktcoins).
6. **Збереження прогресу**:
    - Весь стан гри (ресурси, апгрейди, таймери, скіни) зберігається в **IndexedDB** за допомогою `idb-keyval`. 
    - Прогрес відновлюється після перезавантаження сторінки.

## Додаткові вимоги (Варіант A)
Було обрано **ВАРІАНТ A: Рекомендовані покращення** та реалізовано:
- **Анімація**: Використовується `framer-motion` для анімації натискань та плаваючих цифр при кліку.
- **Оффлайн-дохід**: Після повернення у гру розраховується та нараховується пасивний дохід, зароблений за час відсутності (мінімум 1 хвилина), і відображається модальне вікно.
- **Адаптивність**: Інтерфейс коректно адаптується під мобільні пристрої та планшети (використано CSS Modules).

## Інструкція запуску

1. Переконайтесь, що у вас встановлено Node.js (v16+).
2. Склонуйте/завантажте цей репозиторій.
3. Встановіть залежності:
   ```bash
   npm install
   ```
4. Запустіть сервер для розробки:
   ```bash
   npm run dev
   ```
5. Відкрийте браузер за вказаним посиланням (зазвичай `http://localhost:5173`).
